# Game AI Project

This Unreal Engine project teaches how to work with gameplay AI and mechanics 
like Steering behaviors, Flocking with space partitioning, Graphs, Astar, BFS, Navmeshes and more.

## Extra Assignment

### WEEK 5 Pathfinding Algorithms - Fallback Path
When no path can be found (if the goal is unreachable) find a path to the node closest to the original goal instead
